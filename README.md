# ПК Пульт: управление компьютером с iPhone

- `pc/`: программа для Windows (запуск через `start.bat`)
- `ios/`: исходники приложения для iPhone
- `.github/workflows/build-ipa.yml`: автосборка `.ipa` на бесплатном облачном Mac от GitHub

## 1. Собрать .ipa (без Mac)
1. Зарегистрируйтесь на github.com и нажмите **New repository**. Выберите **Public**
   (для публичных репозиториев облачные Mac бесплатны) и создайте репозиторий.
2. На странице репозитория нажмите **uploading an existing file** и перетащите
   в окно **всё содержимое** этой папки (`.github`, `ios`, `pc`, `README.md`). Затем нажмите **Commit changes**.
   > Если папка `.github` не загрузилась: **Add file → Create new file**, имя
   > `.github/workflows/build-ipa.yml`, вставьте текст этого файла и нажмите Commit.
3. Откройте вкладку **Actions**. Сборка запустится сама и займёт примерно 3–5 минут
   (повторно её можно запустить кнопкой **Run workflow**).
4. Когда появится зелёная галочка, откройте сборку. Внизу, в разделе **Artifacts**,
   скачайте **PCRemote-ipa** и распакуйте zip, внутри будет `PCRemote.ipa`.

## 2. Установить на iPhone (Windows, бесплатно)
1. Установите **iTunes** и **iCloud** с сайта Apple (не из Microsoft Store), затем **Sideloadly** с sideloadly.io.
2. Подключите iPhone кабелем и нажмите «Доверять этому компьютеру».
3. В Sideloadly перетащите `PCRemote.ipa`, введите свой Apple ID и нажмите **Start**.
4. На iPhone:
   - Настройки → Основные → VPN и управление устройством → ваш Apple ID → **Доверять**;
   - для iOS 16 и новее: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → Вкл (потребуется перезагрузка).
5. С бесплатным Apple ID приложение работает **7 дней**. Потом снова нажмите Start
   в Sideloadly с тем же .ipa и тем же Apple ID (настройки сохранятся).
   Чтобы не продлевать вручную, можно включить автообновление в Sideloadly или использовать AltStore.

Есть способ без продления: если на iPhone iOS 14.0–16.6.1 или 17.0,
поставьте TrollStore, и `.ipa` установится навсегда.

## 3. Пользоваться
1. На ПК запустите `pc/start.bat`. В окне появятся адрес и PIN.
2. В приложении введите адрес (например, `192.168.1.5`) и PIN.
   Когда iPhone спросит доступ к «Локальной сети», нажмите **Разрешить**.
3. Чтобы подключиться к другому ПК: ⚙️ → «🖥 Другой ПК».
